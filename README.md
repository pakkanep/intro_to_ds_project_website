## Running the website

### 1. Clone the repository

```bash
git clone <repository-url>
cd intro_to_DS/website
```

### 2. Create the virtual environment

```bash
python -m venv .venv
```

### 3. Activate it

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Mac/Linux:**

```bash
source .venv/bin/activate
```

### 4. Install Flask

```bash
pip install flask
```

### 5. Start the website

```bash
python app.py
```

### 6. Open the website

Go to:

```text
http://127.0.0.1:5000
```

The website should now be running locally.
